#  Incident Lifecycle Management System

## 📌 Project Description

**Incident Lifecycle Management System** is a ServiceNow project developed to manage IT incidents from creation to resolution. It provides a structured process for recording, classifying, assigning, investigating, resolving, and documenting incidents.

## 🎯 Objectives

* Create and manage IT incidents efficiently.
* Classify incidents based on category, subcategory, urgency, and affected services.
* Assign incidents to the appropriate support teams.
* Use Knowledge Articles to support faster troubleshooting.
* Track incident SLAs and resolution progress.
* Manage related and child incidents.
* Document the cause and resolution of incidents.
* Create Knowledge Articles from resolved incidents.

## 🔄 Incident Lifecycle

```text
Incident Creation
       ↓
Incident Classification
       ↓
Assignment to Support Team
       ↓
Investigation
       ↓
Knowledge Assistance
       ↓
SLA Tracking
       ↓
On Hold / Awaiting Change
       ↓
Cause & Resolution
       ↓
Incident Resolution
       ↓
Knowledge Article Creation
```

## ✨ Key Features

### 1. Incident Creation

Creates an incident with details such as caller, short description, and description.

### 2. Incident Classification

Classifies incidents using category, subcategory, urgency, service, service offering, and configuration item.

### 3. Agent Assist

Suggests relevant Knowledge Articles based on the incident details to help the support team troubleshoot issues faster.

### 4. Incident Assignment

Assigns incidents to the appropriate support group, such as Service Desk or Network Support.

### 5. SLA Tracking

Tracks the SLA associated with the incident and helps the support team monitor resolution time.

### 6. Child Incidents

Allows related incidents to be connected with a parent incident for better tracking.

### 7. Cause and Resolution

Records the probable cause and resolution details of the incident.

### 8. Knowledge Article Creation

Creates a Knowledge Article from the resolved incident so the solution can be reused for similar issues.
